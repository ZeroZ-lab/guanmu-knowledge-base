# 05 - Psychology 心理学

## 📘 学科概述

心理学是研究人类心智和行为的科学。学习心理学将帮助你：
- 理解人类思维和行为模式
- 提升自我认知和情商
- 改善人际交往和沟通
- 为教育、管理、产品设计提供洞察

## 🗺️ 学习路线图

```
PSY-101 (心理学导论)
    ↓
PSY-201 (认知心理学) ← AI/认知科学基础
    ↓
PSY-202 (发展心理学) ← 理解人类成长
    ↓
PSY-301 (社会心理学) ← 理解群体行为
```

## 📚 课程列表

### 入门级 (100-level)

|---------|---------|------|------|

**PSY-101 - Introduction to Psychology**
- 先修要求：无
- 内容概要：心理学流派、研究方法、基本概念
- 学习目标：建立心理学基础知识框架
- **推荐优先级**：非常高，通识必修 ⭐⭐

| 课程编号 | 课程名称 | 难度 | 状态 |
|---------|---------|------|------|

| PSY-202 | Developmental Psychology | ⭐⭐ | 📁 待学习 |

**PSY-201 - Cognitive Psychology**
- 先修要求：PSY-101
- 内容概要：注意、记忆、语言、决策
- 学习目标：理解人类信息处理机制
- **特别推荐**：对AI和教育学习者重要 ⭐

**PSY-202 - Developmental Psychology**
- 先修要求：PSY-101
- 内容概要：儿童发展、青少年心理、成人发展
- 学习目标：理解人类各阶段心理特征
- **推荐给**：教育工作者、父母

|---------|---------|------|------|

**PSY-301 - Social Psychology**
- 先修要求：PSY-101
- 内容概要：从众、说服、群体动力、偏见

- **特别推荐**：对管理者、产品经理重要 ⭐

## 🎯 学习建议

1. **科学方法**：重视研究方法和实验设计
2. **自我观察**：将理论应用到观察自己和他人
3. **批判性思考**：警惕心理学中的常见误解
4. **实践应用**：在日常生活中应用心理学原理
5. **跨学科整合**：结合神经科学、经济学、AI
