# 03 - History 历史

## 📘 学科概述

历史帮助我们理解过去，洞察现在，预测未来。学习历史将：
- 培养批判性阅读和分析能力
- 理解社会、政治、经济的演变
- 学习从历史中汲取智慧
- 建立全球化视野和人文素养

## 🗺️ 学习路线图

```
HIST-101 (世界历史概览)
    ↓
HIST-201 (科技史) ← 理解技术发展脉络
    ↓
HIST-301 (思想史) ← 哲学和观念的演变
```

## 🎯 学习建议

1. **建立时间线**：使用时间轴工具组织历史事件
2. **多角度思考**：理解不同文化和立场的历史叙事
3. **连接现在**：将历史事件与当代问题联系
4. **原始资料**：阅读历史文献和第一手资料
5. **跨学科学习**：结合哲学、经济、政治理解历史
