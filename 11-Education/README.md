# 11 - Education 教育学

## 📘 学科概述

教育学研究教与学的理论和实践。学习教育学将：
- 理解学习原理和教学方法
- 提升教学设计能力
- 改进自己的学习方式
- 为教育工作或培训做准备

## 🗺️ 学习路线图

```
EDU-101 (教育学导论)
    ↓
EDU-201 (教育心理学)
    ↓
    ┌─ EDU-301 (课程设计)
    └─ EDU-302 (教学方法)
```

**EDU-101 - Introduction to Education**

- 学习目标：掌握多种教学方法
- **推荐给**：教师、讲师 ⭐

## 🎯 学习建议

1. **理论结合实践**：教育学需要在实践中学习
2. **观察反思**：观察优秀教师的教学
3. **微格教学**：练习小片段的教学
4. **学习科学**：关注学习科学最新研究
5. **技术整合**：了解教育技术工具
6. **学生视角**：从学习者角度思考
