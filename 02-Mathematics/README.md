# 02 - Mathematics 数学

## 📘 学科概述

数学是科学的语言，是定量分析和逻辑推理的基础。学习数学将帮助你：
- 建立严谨的逻辑思维
- 掌握定量分析工具
- 为计算机科学、AI、经济学等打下基础
- 理解抽象概念和模式识别

## 🗺️ 学习路线图

```
MATH-101 (微积分I)
    ↓
MATH-102 (微积分II)
    ↓
MATH-201 (线性代数) ← 为AI/ML准备
    ↓
MATH-202 (统计与概率) ← 数据分析基础
```

## 📚 课程列表

### 入门级 (100-level)

| 课程编号 | 课程名称 | 难度 | 状态 |
|---------|---------|------|------|
| MATH-101 | Calculus I | ⭐⭐ | 📁 待学习 |
| MATH-102 | Calculus II | ⭐⭐ | 📁 待学习 |

**MATH-101 - Calculus I**
- 先修要求：高中数学基础
- 内容概要：极限、导数、微分应用
- 学习目标：理解变化率和优化问题

**MATH-102 - Calculus II**
- 先修要求：MATH-101
- 内容概要：积分、微分方程、级数
- 学习目标：掌握积分技巧和应用

### 中级 (200-level)

| 课程编号 | 课程名称 | 难度 | 状态 |
|---------|---------|------|------|
| MATH-201 | Linear Algebra | ⭐⭐⭐ | 📁 待学习 |
| MATH-202 | Statistics and Probability | ⭐⭐⭐ | 📁 待学习 |

**MATH-201 - Linear Algebra**
- 先修要求：MATH-101
- 内容概要：向量空间、矩阵运算、特征值
- 学习目标：为机器学习和数据科学打基础
- **重要性**：AI/ML 的核心数学基础 ⭐

**MATH-202 - Statistics and Probability**
- 先修要求：MATH-101
- 内容概要：概率论、统计推断、假设检验
- 学习目标：数据分析和决策的数学基础
- **重要性**：数据科学必修 ⭐

## 🎯 学习建议

1. **夯实基础**：确保代数和三角学扎实
2. **大量练习**：数学需要通过习题巩固
3. **可视化理解**：使用图形和几何直觉
4. **应用导向**：结合实际问题学习（如物理、经济）
5. **工具辅助**：使用 Desmos、GeoGebra、Python 等工具
