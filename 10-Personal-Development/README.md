# 10 - Personal Development 个人发展

## 📘 学科概述

个人发展是关于如何更好地学习、工作和生活的元技能。学习个人发展将：
- 提升学习效率和效果
- 改善时间管理和生产力
- 培养成长型思维
- 建立个人系统和习惯

## 🗺️ 学习路线图

```
PD-101 (学习方法论) ← 最优先
    ↓
    ┌─ PD-201 (时间管理)
    └─ PD-202 (生产力系统)
        ↓
    PD-301 (批判性思维与问题解决)
```

**PD-101 - Learning How to Learn**
- 先修要求：无
- 内容概要：记忆原理、间隔重复、费曼技巧、元认知
- 学习目标：掌握科学的学习方法
- **推荐优先级**：最高，所有学习者必修 ⭐⭐⭐
- **建议**：在学习任何其他课程前先学这门课

**PD-301 - Critical Thinking and Problem Solving**

- 内容概要：系统思维、决策框架、问题分解、创造性思维

- **推荐优先级**：高，元技能 ⭐⭐⭐

## 🎯 学习建议

1. **先学方法论**：PD-101应该是第一门课
2. **立即应用**：将学到的方法应用到当前学习中
3. **建立系统**：逐步建立个人学习和工作系统
4. **持续优化**：定期回顾和改进自己的系统
5. **记录反思**：保持学习日志
6. **实验心态**：尝试不同方法，找到适合自己的
