# 01 - Philosophy 哲学

## 📘 学科概述

哲学是批判性思维和逻辑推理的基础。通过学习哲学，你将：
- 培养清晰的思维和论证能力
- 理解伦理学和价值判断的基础
- 学会质疑和分析复杂问题
- 建立系统性的思考框架

## 🗺️ 学习路线图

```
PHIL-101 (入门)
    ↓
PHIL-201 (中级) ← 逻辑和批判性思维
    ↓
PHIL-301 (高级) ← 伦理学应用
```

## 🎯 学习建议

1. **循序渐进**：从 PHIL-101 开始，建立基础概念
2. **实践应用**：将逻辑思维应用到日常决策中
3. **广泛阅读**：阅读经典哲学著作原文
4. **思考练习**：定期进行思想实验和论证分析
