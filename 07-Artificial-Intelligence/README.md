# 07 - Artificial Intelligence 人工智能

## 📘 学科概述

人工智能是计算机科学中最前沿和最具变革性的领域。学习AI将：
- 理解机器学习和深度学习原理
- 掌握AI应用开发能力
- 为未来的技术创新做准备
- 理解AI对社会的影响

## 🗺️ 学习路线图

```
[先修] CS-101, MATH-201, MATH-202
    ↓
AI-101 (AI导论)
    ↓
AI-201 (机器学习) ← 核心基础
    ↓
AI-301 (深度学习)
    ↓
        ┌─ AI-302 (自然语言处理)
        └─ AI-303 (计算机视觉)
```

**AI-201 - Machine Learning**
- 先修要求：CS-101, MATH-201, MATH-202
- 内容概要：监督学习、无监督学习、模型评估、特征工程

| 课程编号 | 课程名称 | 难度 | 状态 |

**AI-301 - Deep Learning**
- 先修要求：AI-201, CS-201
- 内容概要：神经网络、CNN、RNN、Transformer、优化技术
- 学习目标：掌握深度学习框架和应用
- **推荐优先级**：现代AI必备 ⭐⭐⭐

**AI-302 - Natural Language Processing**
- 先修要求：AI-301
- 内容概要：词嵌入、语言模型、机器翻译、大模型(LLM)
- 学习目标：掌握NLP技术和应用
- **热门领域**：ChatGPT等大模型 ⭐⭐

**AI-303 - Computer Vision**
- 先修要求：AI-301
- 内容概要：图像分类、目标检测、图像分割、生成模型
- 学习目标：掌握计算机视觉技术
- **应用广泛**：自动驾驶、医疗影像等 ⭐⭐

## 🎯 学习建议

1. **数学基础**：必须先掌握线性代数和概率统计
2. **编程能力**：Python必须熟练，NumPy/Pandas必备
3. **从小做起**：从简单数据集开始（如MNIST）
4. **框架实践**：掌握PyTorch或TensorFlow
5. **论文阅读**：跟进最新研究（arXiv.org）
6. **项目实践**：Kaggle竞赛、个人项目
7. **GPU学习**：了解如何使用GPU加速训练
