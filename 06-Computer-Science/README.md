# 06 - Computer Science 计算机科学

## 📘 学科概述

计算机科学是研究计算、信息处理和自动化的学科。学习计算机科学将：
- 培养编程和问题解决能力
- 理解计算机系统的工作原理
- 为软件开发和技术创新打基础
- 开启AI、数据科学等高级领域的大门

## 🗺️ 学习路线图

```
CS-101 (编程入门)
    ↓
CS-201 (数据结构与算法) ← 核心基础
    ↓
CS-202 (计算机体系结构)
    ↓
        ┌─ CS-301 (操作系统)
        ├─ CS-302 (计算机网络)
        └─ CS-303 (数据库系统)
```

- 学习目标：掌握数据库设计和使用

## 🎯 学习建议

1. **动手实践**：编程必须通过大量练习
2. **项目驱动**：每学完一个概念就用项目巩固
3. **代码阅读**：阅读优秀开源项目的代码
4. **算法练习**：LeetCode、HackerRank 刷题
5. **系统理解**：不只学语法，要理解底层原理
6. **版本控制**：从一开始就使用 Git
