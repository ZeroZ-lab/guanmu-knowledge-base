# CS-101: Introduction to Programming

## 📋 Course Information

**Course Code**: CS-101  
**Level**: Introductory (100-level)  
**Prerequisites**: None (Basic math recommended)  
**Estimated Time**: 12 weeks, 8-10 hours per week  
**Programming Language**: Python 3.x

## 🎯 Course Goals

By the end of this course, you will be able to:

1. **Think Computationally**: Break down problems into algorithmic steps
2. **Write Python Programs**: Create functional programs with good practices
3. **Understand Core Concepts**: Variables, control flow, functions, data structures
4. **Debug Code**: Identify and fix common programming errors
5. **Build Projects**: Complete several small projects demonstrating your skills

## 🛠️ Required Setup

### Python Installation

1. Download Python 3.x from [python.org](https://www.python.org/downloads/)
2. Install with "Add to PATH" option
3. Verify installation:
   ```bash
   python --version
   # Should show Python 3.x.x
   ```

**For Beginners**:

## 🎓 Learning Strategies

### Best Practices

1. **Type Code Yourself**: Don't just read - write code!
2. **Experiment**: Modify examples to see what happens
3. **Debug Often**: Learn to read error messages
4. **Build Projects**: Apply what you learn immediately
5. **Ask Questions**: Use Stack Overflow, Reddit r/learnpython

### Time Management

- **Daily**: 1-2 hours coding practice
- **Weekly**: Complete one module
- **Projects**: Start early, iterate often

### Common Pitfalls to Avoid

1. ❌ Tutorial Hell - just watching without coding
2. ❌ Not reading error messages
3. ❌ Skipping fundamentals to learn "advanced" topics
4. ❌ Not breaking problems into smaller parts
5. ❌ Comparing yourself to others
