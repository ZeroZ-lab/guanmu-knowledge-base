## Course Description

This course introduces fundamental programming concepts using Python. Students will learn to think computationally, write clean code, and build practical programs. No prior programming experience is required.

---

## Learning Outcomes

Upon successful completion of this course, students will be able to:

1. Understand and apply basic programming concepts (variables, types, operators)
2. Use control structures (conditionals and loops) effectively
3. Write and use functions to organize code
4. Work with Python's built-in data structures (lists, dictionaries, tuples, sets)
5. Handle files and user input
6. Debug code and handle errors gracefully
7. Understand basic object-oriented programming principles
8. Complete programming projects independently

## Course Schedule

### Week 00: Setup and Orientation
- Install Python
- Set up development environment
- Hello World program

### Week 01: Variables and Data Types
- Variables and assignment
- Numbers, strings, booleans
- Type conversion
- Basic operators

### Week 02: Control Flow
- If/elif/else statements
- Comparison and logical operators
- While loops
- For loops

### Week 03: Functions
- Defining functions
- Parameters and arguments
- Return values
- Scope
- Lambda functions

### Week 04: Lists and Tuples
- Creating and accessing lists
- List methods
- List comprehensions
- Tuples and immutability

### Week 05: Dictionaries and Sets
- Dictionary basics
- Dictionary methods
- Sets and set operations
- Choosing the right data structure

### Week 06: String Manipulation
- String methods
- String formatting
- Regular expressions (basic)
- Text processing

### Week 07: File I/O
- Reading files
- Writing files
- Working with CSV
- File paths and directories

### Week 08: Error Handling
- Understanding errors
- Try/except blocks
- Raising exceptions
- Debugging techniques

### Week 09: Object-Oriented Programming
- Classes and objects
- Attributes and methods
- Inheritance (basic)
- When to use OOP

### Week 10: Libraries and Modules
- Importing modules
- Standard library overview
- Installing packages (pip)
- Popular libraries introduction

### Week 11: Final Project
- Project planning
- Implementation
- Testing and debugging
- Documentation

### Week 12: Review and Next Steps
- Course review
- Best practices summary
- Next learning paths
- Portfolio building tips

## Assessment Methods

This is a self-paced course. Track your progress through:

### Weekly Exercises (Practice)
- 5-10 problems per week
- Check solutions in code/ folder
- Self-grade and review

### Mini Projects (Application)
- 3-4 small projects throughout course
- Build practical applications
- Portfolio pieces

### Final Project (Synthesis)
- Independently designed project
- Demonstrates course concepts
- 50-200 lines of code
- Documented and tested

## Study Tips

1. **Code Daily**: Even 30 minutes helps
2. **Type, Don't Copy**: Muscle memory matters
3. **Experiment**: Break code to understand it
4. **Build Projects**: Apply what you learn
5. **Ask Questions**: Use online communities
6. **Review Regularly**: Spaced repetition works
