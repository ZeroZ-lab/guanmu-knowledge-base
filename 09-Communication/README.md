# 09 - Communication 沟通技能

## 📘 学科概述

沟通是人类最重要的技能之一。良好的沟通能力将：
- 提升人际关系质量
- 增强职场竞争力
- 改善领导力和影响力
- 帮助清晰表达想法

## 🗺️ 学习路线图

```
COMM-101 (写作技能)
    ↓
COMM-201 (公共演讲)
    ↓
COMM-301 (专业沟通)
```

## 📚 课程列表

### 入门级 (100-level)

| 课程编号 | 课程名称 | 难度 | 状态 |
|---------|---------|------|------|
| COMM-101 | Writing Skills | ⭐⭐ | 📁 待学习 |

**COMM-101 - Writing Skills**
- 先修要求：无
- 内容概要：清晰写作、结构化思维、不同文体、编辑技巧
- 学习目标：掌握有效写作能力
- **推荐优先级**：极高，所有人必备 ⭐⭐⭐

| 课程编号 | 课程名称 | 难度 | 状态 |

| 课程编号 | 课程名称 | 难度 | 状态 |

**COMM-301 - Professional Communication**

- 学习目标：掌握职场高级沟通技能
- **推荐给**：职场人士、管理者 ⭐⭐

## 🎯 学习建议

1. **大量实践**：沟通技能只能通过实践提升
2. **录音录像**：记录自己的演讲并回顾
3. **寻求反馈**：主动询问他人的评价
4. **观察学习**：学习优秀演讲者的技巧
5. **加入组织**：如Toastmasters演讲会
6. **日常应用**：在日常生活中刻意练习
