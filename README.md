# 📚 Guanmu Knowledge Base

欢迎来到我的个人知识库！这是一个系统化的学习资料库，采用大学图书馆分类体系，涵盖多个学科领域的学习内容。

## 🎯 关于本知识库

本知识库旨在：
- 系统化地组织和管理各学科的学习资料
- 提供清晰的学习路径和难度标识
- 便于查阅和复习已学内容
- 支持跨平台迁移和托管

## 📖 课程难度级别说明

所有课程采用编号系统标识难度：

- **100-199**: Introductory (入门级) - 适合初学者，无需先修课程
- **200-299**: Intermediate (中级) - 需要基础知识，建议完成相关100级课程
- **300-399**: Advanced (高级) - 需要扎实基础，适合深入学习
- **400-499**: Graduate/Expert (研究生/专家级) - 专业深度内容

## 📝 使用指南

### 文件结构说明

```
学科目录/
├── README.md                    # 学科概览和学习路线图
├── Topics/                      # 专题文章（跨课程主题）
└── DEPT-XXX-Course-Name/        # 具体课程
    ├── 00-Overview/             # 课程概述
    ├── 01-Week-01-Topic/        # 第一周内容
    │   ├── notes.md            # 笔记
    │   ├── exercises.md        # 练习题
    │   ├── code/               # 代码示例
    │   └── resources/          # 相关资源
    └── ...
```

### 如何使用

1. **浏览学习**：从主导航选择感兴趣的学科
2. **系统学习**：参考推荐学习路径，按顺序学习
3. **查阅复习**：使用课程编号快速定位内容
4. **扩展学习**：查看 Topics 文件夹中的专题文章

### 内容约定

- 所有链接使用相对路径，方便迁移
- 课程编号反映难度和先修要求
- 每个章节自包含（笔记、代码、资源）
- Markdown 格式，兼容所有文档托管平台
